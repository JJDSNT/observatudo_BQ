# AI_context/specs

## Objetivo

Especificações formais — a fonte de definição a partir da qual issues
podem ser derivadas (`spec_id` opcional no frontmatter da issue).

Neste projeto, a arquitetura estável já vive em `docs/architecture.md` e
`docs/monorepo-structure.md` (fora do `AI_context`, ver `../README.md`).
Use esta pasta para especificar trabalho **futuro** ainda não decidido em
detalhe — não para redocumentar o que já está em `docs/`.

## Status permitidos

`draft`, `validated`, `active`, `deprecated`

## Versionamento

Não há tabela de versões: o histórico de uma Spec é o próprio git log do
arquivo.
